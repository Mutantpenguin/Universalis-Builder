# Universalis Builder

This program is required for the tabletop skirmisher [Universalis](https://mutantpenguin.github.io/Universalis/).

To play Universalis, you have to decide on a universe and put together a group of models.

The rulebook itself does not provide any help with this and only contains generic information.

This is where _Universalis Builder_ comes into play, allowing you to create universes with their archetypes, equipment, weapons, armor and powers.
